## 3. Audio & Music Engine

- **Web Audio API Synth Engine (`src/utils/audioSynth.js`)**:
  - Dynamically synthesizes real-time 124 BPM synthwave chords and arpeggiated melodies.
  - Zero external MP3 network dependencies required.
  - Generates realistic white-noise candle blowing puffs, sci-fi unlock sub-drops, and fanfare chords.

- **Custom Audio Support**:
  - Simply place any MP3 audio file into `public/audio/birthday-beats.mp3` to play custom music.
